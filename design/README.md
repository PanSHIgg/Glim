# Glim 终端设计

直接打开 `prototype.html`。附带的 CSS、JavaScript 为本地文件，没有网络资源或构建步骤。

## 设计方向

核心任务是阅读终端输出、切换会话，以及安排多个终端。工作区占据窗口主体；不加入侧栏、统计卡片或其他无关区域。

相较于 `demo/design/prototype.html`：

- 用平整的窗格和单条分隔线替代大圆角卡片、间隙和独立阴影。
- 以标题底色和文字强弱表示当前窗格，暖色描边只用于键盘焦点、拖拽目标和布局预览。
- 使用暖灰背景、克制的米金强调色；终端的绿、黄、蓝分别表示结果、变更和地址。
- 主终端默认占左侧约三分之二，右侧上下分屏；终端字号与行距更易阅读。
- 全局分屏、布局入口保持可见。浅色 / 深色 / 跟随系统的胶囊主题开关位于窗口右下角；状态评审工具放在窗口之外。
- 布局缩略图加入名称、当前选中状态和取消提示，指针与键盘操作采用同一套动作。
- 新增可拖动及键盘调整的分隔线、单窗格聚焦、清晰的底部会话状态。

深色是默认预览，浅色使用相同的层级。配色、间距、字体和圆角集中定义在 `styles.css` 的主题令牌中。

## 可操作的交互

| 操作 | 入口 |
| --- | --- |
| 新建标签页 | 标签栏 `＋` / `Ctrl+Shift+T` |
| 切换标签页 | 点击标签 / `Ctrl+Tab` / 聚焦标签后用左右方向键 |
| 关闭标签页 | 标签上的关闭按钮；最后一个关闭后显示空状态 |
| 向右 / 向下分屏 | 工具栏或窗格的分屏菜单 / `Ctrl+Shift+D`、`Ctrl+Shift+E` |
| 关闭当前窗格 | 窗格的关闭按钮 / `Ctrl+Shift+W` |
| 聚焦窗格 / 恢复分屏 | 窗格的展开按钮 / `Ctrl+Shift+Enter` |
| 打开布局面板 | 工具栏 `布局…` / `Alt+Z` / 将窗格标题拖到工作区顶部 |
| 预览并应用布局 | 悬停缩略图后点击；键盘方向键选方案，`Enter` 应用 |
| 交换窗格 | 将标题拖到另一窗格；或 `Ctrl+Shift+方向键` |
| 切换当前窗格 | 点击或聚焦窗格 / `Alt+方向键` |
| 调整比例 | 拖动分隔线；聚焦分隔线后按对应方向键，`Home` 回到均分 |
| 取消操作 | `Esc`；面板关闭后焦点回到触发控件 |

布局预览不会修改实际布局；取消后回到原先的比例。分屏、交换、切换标签和聚焦操作保留会话身份与输出滚动位置。分屏菜单在窗口边缘自动向内放置。主题选择会记住，系统主题会响应系统变化。

预览状态按钮可反复恢复初始工作区并展示布局、分屏、交换和空状态。也可用 `prototype.html?view=layout#dark` 或 `prototype.html#light` 直接进入指定状态。

## 尺寸与键盘

舒适窗口尺寸约为 1200 × 750；建议正式应用最小窗口为 800 × 600。窗口变窄时先隐藏次要进程文字，再收起工具栏文字，保留图标和快捷键入口。每个终端独立滚动，滚动条贴在终端边缘。

分隔线以终端内容的最小宽度和高度限制拖动比例；相邻窗格只由分隔线绘制一次边界。间距和字号使用相对单位，支持放大预览和较大系统字体。操作按钮常驻，键盘焦点清晰可见；运行状态同时显示圆点和“运行中”，减少对颜色的依赖。减少动态效果设置会停止光标闪烁。

## GPUI 实现映射

此阶段交付为可交互 HTML 设计稿，终端内容是固定示例。HTML 中的菜单、焦点和拖拽代码用于确认设计行为；正式 GPUI 实现应使用组件与 Actions 承接这些行为。

| 设计对象 | 实现方向 |
| --- | --- |
| 窗口与标题栏 | `gpui-kit` 的窗口、`TitleBar`，保留原生拖动区与平台装饰 |
| 标签与常用操作 | `TabBar`、`Tab`、`Button`，按会话 ID 保持身份 |
| 分屏树与会话 | 工作区拥有分屏树、活动窗格和会话 ID；终端输出实体独立持有 |
| 分隔线 | `Resizable` 及窗格最小尺寸约束 |
| 分屏菜单 | `DropdownMenu` / `PopupMenu`，统一焦点、方向键和关闭行为 |
| 布局面板 | `Popover`，布局只是预览时不写入工作区模型 |
| 快捷键 | 共用 GPUI Actions，按钮与菜单调用同一操作 |
| 颜色与密度 | `cx.theme()` 的语义令牌及产品主题扩展；使用 rem 尺寸与组件 Size |
| 终端 | 后续接入 PTY、ANSI 解析与 GPU 文本网格渲染 |

原生应用（阶段 4）的实现备注：

- 布局面板是窗格区域内的浮层（右上角），带遮罩点击关闭；未使用 `Popover`，因为面板既能由工具栏打开，也能在拖动标题进入顶部热区时出现，位置与触发器无关。
- 布局预览渲染占位窗格而不是真实终端：真实终端在预览尺寸下会向 PTY 发送尺寸变化，预览不应改变 shell 或 TUI 状态。缩略图与预览都使用同一套方案形状（`crates/glim_workspace/src/layout.rs`）。
- 分隔线、窗格标题都支持键盘路径：分隔线聚焦后方向键调整比例、`Home` 等分；`Ctrl+Shift+方向键` 交换窗格；面板内方向键选择、`Enter` 应用、`Esc` 取消。

原生应用（阶段 5）的实现备注：

- 设置对话框是模态表单（主题分段、字体族与字号、默认 shell、滚动历史），`保存` 才写回配置；校验或保存失败时对话框保持打开并显示原因。
- 高级设置（shell 环境变量、更新版本的未知字段）保留在 `config.toml`，界面保存不会丢弃；`打开配置文件位置…` 在系统文件管理器中定位配置文件。
- 配置与工作区数据都写入平台配置目录（Windows `%APPDATA%\Glim`），采用「临时文件 + 原子替换」；无效文件按默认启动并提示，目录缺失回退到用户目录并提示。

本原型没有执行系统命令。截图中的构建与测试日志是终端排版示例，不是本项目的编译、测试结果。

## 验证与截图

已使用 Edge 浏览器实际渲染，通过 30 项交互检查，覆盖分屏、标签切换和关闭、拖拽交换、拖到顶部应用布局、取消预览、焦点恢复、分隔线调整、聚焦和恢复、空状态恢复、主题切换及减少动态效果。JavaScript 语法检查通过，浏览器无运行时异常。

检查了 1440 × 1000 与 840 × 720 视口，并在小视口下将基础字号放大到 20px，确认页面无横向溢出，分屏菜单保持在窗口内。对布局预览和取消后的窗格宽度做了几何检查。
